# ちゃんとRatedで出なければならない

私は以前からアルゴリズムを勉強していて、特に最も利用しているのがAtCoderです。

しかし、毎週のコンテストにきっちり出ているかというとそんなことは全くなく、過去問をチェリーピックしてひたすら解いています（Ratedで出るのは1年に1回あるかどうか）。

しかも、1度解いた問題を他の言語で解きなおすことに注力していた時期がありました。普段はRustで解いているのですが、F# / Haskell / Ocaml / Erlang / Elixir / C / Common Lisp でひたすら解いていました。A ~ B問題ならあまり違いはないですが、C問題くらいからだんだん言語によって

「AtCoderやってます！」→「そうなんですか！何色ですか？」→「灰色です、、、」。これは何というか、別に悪いことではないんですが、まぁ格好良くはないですよね。

し、この歳になるとこういう形式のゲームを楽しむのは中々難しい。

## ちゃんと理解しなければならない

レートを上げにモチベがなく、グラフ系の問題ばかりえり好みしていましたから、E ~ Fのグラフ系問題を解けてもC問題が解けないことにショックを受けました。
